# ルール論理式の完全ガイド

## 1. 基本的な考え方

`ルール設定`シートの`論理式（TRUEなら問題なし）`列へ、条件を論理式で入力します。

- 式の結果が`TRUE`：問題なし
- 式の結果が`FALSE`：`判定`列に従ってエラーまたは警告
- 式そのものが不正：設定エラーとなり、フォーム下書きを作成しない

例：対象競技へ男子2名以上、女子2名以上が必要な場合

```text
M >= 2 && F >= 2
```

論理式の解析機能自体は、先頭の`=`が付いた文字列も受け付けます。ただし、Google Sheetsのセルへ直接入力すると数式として解釈されるため、通常は`=`を付けないでください。

```text
M >= 2 && F >= 2
```

外部ファイルから先頭`=`付きの文字列を取り込む必要がある場合は、セル上で文字列として保存されていることを確認してください。

ただし、等しいことを比べる演算子は`=`ではなく`==`です。

```text
N == 4     正しい
N = 4      誤り
```

## 2. ルール設定の入力手順

1. `rule_id`へ重複しないIDを入力します。例：`R101`
2. `有効`へチェックを入れます。
3. `ルール名`へ担当者が理解できる名前を入力します。
4. `判定`を`エラー`または`警告`にします。
5. `表示メッセージ`へ、FALSEのとき利用者へ見せる文章を入力します。
6. `論理式（TRUEなら問題なし）`へ式を入力します。
7. 右側の緑色の対象競技列へチェックを入れます。
8. `設定を点検`を実行します。

新しいルールでは、非表示の`旧条件（互換）`と`旧上限（互換）`は入力しません。これらは従来ルールを動かすためだけに残しています。

学籍番号不正、クラス不一致、氏名差異、必須枠などは、従来からある基本検査も引き続き動きます。同じ内容を論理式でも設定すると、1件の不備に対して基本検査と論理式ルールの両方が表示されることがあります。競技固有の条件を追加するときは論理式を使い、基本検査と同じ条件を重ねる場合は、二重表示が必要か確認してください。

## 3. 使用できる変数

変数名の大文字・小文字は区別しません。たとえば`M`と`m`は同じです。

| 変数 | 意味 | 数え方 |
|---|---|---|
| `M` | 男子の登録数 | 登録状態が`選手を登録する`で、生徒マスターの性別がMの枠 |
| `F` | 女子の登録数 | 登録状態が`選手を登録する`で、生徒マスターの性別がFの枠 |
| `N` | 登録数 | 登録状態が`選手を登録する`の枠数 |
| `UNKNOWN` | 性別不明数 | 登録済みだがM/Fを確認できない枠数。学籍番号不正・生徒マスター未登録も含む |
| `EMPTY` | 出場しない枠数 | 登録状態が`出場しない`の枠数 |
| `REQUIRED_EMPTY` | 必須未登録枠数 | 必須枠で、登録状態が`選手を登録する`以外の枠数 |
| `UNIQUE` | 選手数 | 空欄でない学籍番号の種類数。`UNIQUE >= 40`のような「足りない」形で成立しない場合、承認画面の修正方法に未登録の生徒を並べる |
| `DUPLICATE` | 重複超過数 | 同じ学籍番号の2件目以降の合計数 |
| `MAX_PER_STUDENT` | 1人の最大登録数 | 最も多く登録された学籍番号の登録数。登録なしは0 |
| `INVALID_ID` | 不明な学籍番号数 | 生徒マスターで確認できない登録済み枠数。未入力も含む |
| `NAME_MISMATCH` | 氏名差異数 | 学籍番号は確認できるが、正規化後の氏名が生徒マスターと異なる枠数 |
| `CLASS_MISMATCH` | クラス不一致数 | 学籍番号は確認できるが、対象学年・組と所属が異なる枠数 |
| `PENDING` | 調整中枠数 | 登録状態が`現在調整中`の枠数 |
| `CLASS_SIZE` | 名簿の人数 | 対象クラス（申請の対象学年・組）の生徒マスターの人数。登録内容ではなく名簿から数える |
| `CLASS_M` | 名簿の男子人数 | 対象クラスの生徒マスターで性別がMの人数 |
| `CLASS_F` | 名簿の女子人数 | 対象クラスの生徒マスターで性別がFの人数 |

英語の別名も一部使用できます。

| 別名 | 同じ意味 |
|---|---|
| `MALE` | `M` |
| `FEMALE` | `F` |
| `TOTAL` | `N` |
| `UNKNOWNS` | `UNKNOWN` |

運用では短い正式名の`M`、`F`、`N`、`UNKNOWN`を推奨します。

## 4. 使用できる演算子

### 比較

| 演算子 | 意味 | 例 |
|---|---|---|
| `==` | 等しい | `N == 4` |
| `!=` | 等しくない | `M != F` |
| `>=` | 以上 | `M >= 2` |
| `<=` | 以下 | `MAX_PER_STUDENT <= 1` |
| `>` | より大きい | `M > F` |
| `<` | より小さい | `EMPTY < 2` |

### 論理演算

| 演算子 | 英語表記 | 意味 | 例 |
|---|---|---|---|
| `&&` | `AND` | 両方を満たす | `M >= 2 && F >= 2` |
| `||` | `OR` | どちらかを満たす | `M == 0 || F == 0` |
| `!` | `NOT` | TRUE/FALSEを反転 | `!(EMPTY > 0)` |

`AND`、`OR`、`NOT`も大文字・小文字を区別しません。

```text
M >= 2 AND F >= 2
M >= 2 and F >= 2
```

### 四則演算

| 演算子 | 意味 | 例 |
|---|---|---|
| `+` | 加算 | `M + F == N` |
| `-` | 減算 | `N - UNIQUE == 0` |
| `*` | 乗算 | `M * 2 >= N` |
| `/` | 除算 | `M / 2 >= 1` |
| `%` | 余り | `N % 2 == 0` |

小数と負数も使用できます。

```text
N >= 3.5
N - EMPTY >= -1
```

0で割る式は設定・判定エラーになります。`設定を点検`では各変数を0として式の安全性も確認するため、`M / N`のように人数変数を分母に置く式は設定時点でエラーになります。人数比率は除算を使わず、乗算で書いてください。

```text
M / N >= 0.5     Nが0ならエラーになる
M * 2 >= N       こちらを推奨
```

### 入力上の制限

- 1つの論理式は500文字以内です。
- 半角・全角スペースや改行は無視されます。
- 英字の大文字・小文字は区別しません。
- 全角英数字・記号は可能な範囲で半角へ正規化しますが、式は半角での入力を推奨します。
- 数値は`4`、`3.5`、`.5`の形式を使用します。桁区切りの`,`や指数表記`1e3`は使えません。
- 負数の`-1`は使えますが、単項プラスの`+1`は使えません。
- `1 < N < 4`のような比較の連結は使えません。`N > 1 && N < 4`と書きます。
- べき乗`^`、文字列、配列、関数呼び出しは使えません。

## 5. 計算の優先順位

上から順に先に計算します。

1. 括弧`()`
2. 否定`!`、`NOT`、負数の`-`
3. 乗算・除算・余り`* / %`
4. 加算・減算`+ -`
5. 比較`>= <= > < == !=`
6. AND`&& AND`
7. OR`|| OR`

迷う場合は括弧を入れてください。

```text
(M >= 2 && F >= 2) || N == 0
M + F == N && UNKNOWN == 0
```

## 6. 性別に関する式

### 男子のみ

```text
F == 0 && UNKNOWN == 0
```

`M > 0`も必須にする場合：

```text
M > 0 && F == 0 && UNKNOWN == 0
```

### 女子のみ

```text
M == 0 && UNKNOWN == 0
```

少なくとも1人の女子を必須にする場合：

```text
F > 0 && M == 0 && UNKNOWN == 0
```

### 男子・女子を各1名以上

```text
M >= 1 && F >= 1
```

### 男子・女子を各2名以上

```text
M >= 2 && F >= 2
```

### 男子2名以上、女子3名以上

```text
M >= 2 && F >= 3
```

### 男子ちょうど2名、女子ちょうど2名

```text
M == 2 && F == 2
```

### 男子と女子が同数

```text
M == F && UNKNOWN == 0
```

0人対0人でもTRUEになります。登録者がいることも必要なら：

```text
N > 0 && M == F && UNKNOWN == 0
```

### 男子が女子以上

```text
M >= F
```

### 男女どちらか一方だけ

```text
(M == 0 || F == 0) && UNKNOWN == 0
```

登録者が最低1名必要なら：

```text
N > 0 && (M == 0 || F == 0) && UNKNOWN == 0
```

### 男女が両方いる

```text
M > 0 && F > 0
```

### 性別不明を許可しない

```text
UNKNOWN == 0
```

### 男子が全体の半数以上

```text
M * 2 >= N
```

性別不明も禁止する場合：

```text
M * 2 >= N && UNKNOWN == 0
```

## 7. 合計人数・空欄に関する式

### 登録人数がちょうど4名

```text
N == 4
```

### 登録人数が4名以上

```text
N >= 4
```

### 登録人数が2～4名

```text
N >= 2 && N <= 4
```

### 登録者が1名以上

```text
N > 0
```

### 必須枠をすべて登録

```text
REQUIRED_EMPTY == 0
```

### `出場しない`を許可しない

```text
EMPTY == 0
```

### `出場しない`は1枠まで

```text
EMPTY <= 1
```

### 調整中を許可しない

```text
PENDING == 0
```

### 登録、出場しない、調整中を合わせた確認

```text
N + EMPTY + PENDING >= 4
```

## 8. 重複・1人あたり上限に関する式

### 同じ選手の重複を禁止

```text
MAX_PER_STUDENT <= 1
```

または：

```text
DUPLICATE == 0
```

### 1人2枠まで

```text
MAX_PER_STUDENT <= 2
```

### 登録枠数と選手数が同じ

```text
N == UNIQUE
```

### クラス全員を出す

```text
UNIQUE >= CLASS_SIZE
```

`CLASS_SIZE`は対象クラスの名簿の人数なので、39人のクラスでも41人のクラスでも同じ論理式で「全員」を表せます。`UNIQUE >= 40`のように人数を直接書くと、39人のクラスでは全員を登録しても満たせません。男子全員なら`M >= CLASS_M`、女子全員なら`F >= CLASS_F`と書きます。

満たせない場合、承認画面の`修正方法`に「未登録の生徒（N人。名簿S人のうち登録済みR人）：学籍番号 氏名（性別）、…」が付き、対象クラスの名簿のうち対象競技に登録されていない生徒が出席番号順に分かります。`M >= CLASS_M`のように男子だけを数える論理式では未登録の男子だけ、`F`だけなら未登録の女子だけを並べます。全員登録済みなのに満たせない場合は「未登録の生徒：なし（対象クラスの名簿S人は全員登録済みです）」と、論理式の人数が名簿より多くないかの確認を促す文が出ます。

空欄の学籍番号も同時に禁止する場合：

```text
N == UNIQUE && INVALID_ID == 0
```

### 重複超過を1件まで許可

```text
DUPLICATE <= 1
```

## 9. 入力不備に関する式

### 生徒マスターにない学籍番号を禁止

```text
INVALID_ID == 0
```

### 氏名差異を許可しない

```text
NAME_MISMATCH == 0
```

通常は氏名差異を警告にする既存ルールを使用します。論理式でエラーに変える場合だけ使用してください。

### 別クラスの選手を禁止

```text
CLASS_MISMATCH == 0
```

### 学籍番号・氏名・所属をまとめて確認

```text
INVALID_ID == 0 && NAME_MISMATCH == 0 && CLASS_MISMATCH == 0
```

### 登録状態も含め、完全に確定していることを確認

```text
INVALID_ID == 0 && NAME_MISMATCH == 0 && CLASS_MISMATCH == 0 && PENDING == 0
```

## 10. 複合条件の例

### 4名登録し、男女各2名、重複なし

```text
N == 4 && M == 2 && F == 2 && UNKNOWN == 0 && MAX_PER_STUDENT <= 1
```

### 4名以上、男女各1名以上、空欄・重複なし

```text
N >= 4 && M >= 1 && F >= 1 && REQUIRED_EMPTY == 0 && DUPLICATE == 0
```

### 男子のみ、3名、学籍番号不備なし

```text
N == 3 && M == 3 && F == 0 && UNKNOWN == 0 && INVALID_ID == 0
```

### 男女同数、偶数人数、重複なし

```text
N > 0 && N % 2 == 0 && M == F && UNKNOWN == 0 && DUPLICATE == 0
```

### 2～6名、男女両方、調整中なし

```text
N >= 2 && N <= 6 && M > 0 && F > 0 && PENDING == 0
```

## 11. 対象競技と集計範囲

論理式は、右側でチェックした対象競技の枠だけを集計します。

### 1競技だけチェックした場合

その競技だけで`M`、`F`、`N`などを数えます。

### 複数競技をチェックした場合

チェックした複数競技を合計して数えます。競技ごとに別々の条件としては判定しません。

例：100m走とリレーをチェックし、`N == 6`とした場合、2競技を合わせて6枠ならTRUEです。

競技ごとに4名必要なら、各競技に対してルール行を分けてください。

| ルール名 | 対象競技 | 論理式 |
|---|---|---|
| 100m走は4名 | 100m走だけチェック | `N == 4` |
| リレーは4名 | リレーだけチェック | `N == 4` |

### 修正フォームの場合

修正フォームは1回答につき1競技です。その申請に含まれている対象競技だけを判定します。ルールでチェックされていても、その修正申請に含まれない競技はFALSE判定しません。

### クラスごとの判定

1件の申請に含まれる対象クラスの登録内容で判定します。他クラスや過去申請を横断した学校全体の集計ではありません。

## 12. エラーと警告の使い分け

### エラー

FALSEの場合、申請を承認できません。必ず修正が必要な条件に使用します。

例：

- 必須の男女構成
- 人数不足
- 学籍番号不正
- クラス不一致
- 禁止されている重複

### 警告

FALSEでも、担当者が内容を確認して理由を残せば承認できます。

例：

- 推奨する男女比
- 推奨人数
- 氏名表記差
- 原則的な重複制限に例外を認める場合

## 13. TRUEとFALSEを直接使う

常に問題なし：

```text
TRUE
```

常に問題として表示：

```text
FALSE
```

一時的な試験以外では、常時TRUE/FALSEのルールを有効にしないでください。

## 14. 使用できない書き方

### スプレッドシート関数

```text
AND(M>=2,F>=2)      使用不可
IF(M>=2,TRUE,FALSE) 使用不可
COUNTIF(...)        使用不可
```

次のように書きます。

```text
M >= 2 && F >= 2
```

### JavaScript

```text
Math.max(M,F) >= 2
SpreadsheetApp.getActive()
M >= 2; F >= 2
```

これらは使用できず、実行もされません。

### 日本語の変数

```text
男子 >= 2
女子 >= 2
```

変数は`M`、`F`などの英字名を使用します。

### 単独の数値・計算結果

```text
M + F
N
4
```

最終結果がTRUE/FALSEにならないため使用できません。比較を追加します。

```text
M + F == N
N >= 1
N == 4
```

### 1個の等号による比較

```text
N = 4
```

比較には`==`を使用します。

```text
N == 4
```

## 15. よくある間違い

### 「男子のみ」を`M > 0`だけで表す

`M > 0`は男子が1人以上いるだけで、女子がいてもTRUEです。

```text
M > 0 && F == 0 && UNKNOWN == 0
```

### 「男女同数」で0人も通過する

`M == F`は0対0でもTRUEです。最低1人必要なら`N > 0`を追加します。

```text
N > 0 && M == F
```

### 性別不明を見落とす

男子のみ・女子のみ・男女比を厳密に判定する場合は、通常`UNKNOWN == 0`も追加します。

### 複数競技をチェックし、競技ごとの人数だと思う

複数チェックは合算です。競技ごとの判定はルール行を分けます。

### 0除算をORで避けようとする

式は構文全体を検査・評価し、設定点検では人数変数を0として確認します。そのため、次の式は`N == 0`を先に書いても設定エラーになります。

```text
N == 0 || M / N >= 0.5
```

乗算へ書き換えてください。

```text
M * 2 >= N
```

### 式を変更したのに再検査しない

ルールは申請を検査するたびに読み直します。式を変えただけでは、すでに受信した申請の警告・エラーは変わりません。再検査して初めて新しい式の結果になります。

フォームを公開した後でも、受付を止めずにルールだけ変えられます。`選手登録管理` → `フォーム・競技設定`から次の順に操作します。

1. `ルール設定だけを変更する`（理由を入力）
2. `ルール設定を開く`で式を直す
3. `ルール変更を確定して全申請を再検査`

3の操作で設定点検と全申請の再検査までまとめて実行します。編集をやめる場合は`ルール変更を取り消す`で元の式へ戻ります。

競技設定やフォーム設計も一緒に変える場合だけ、`受付を停止して設定変更を開始`からフォームを作り直します。この操作はフォームのURLが変わるため、ルールだけを直したいときには使いません。

## 16. 推奨テンプレート

| 目的 | 論理式 |
|---|---|
| 男子のみ | `M > 0 && F == 0 && UNKNOWN == 0` |
| 女子のみ | `F > 0 && M == 0 && UNKNOWN == 0` |
| 男女各1名以上 | `M >= 1 && F >= 1 && UNKNOWN == 0` |
| 男女各2名以上 | `M >= 2 && F >= 2 && UNKNOWN == 0` |
| 男女同数 | `N > 0 && M == F && UNKNOWN == 0` |
| 4名ちょうど | `N == 4` |
| 2～4名 | `N >= 2 && N <= 4` |
| 必須枠をすべて登録 | `REQUIRED_EMPTY == 0` |
| 調整中なし | `PENDING == 0` |
| 重複なし | `MAX_PER_STUDENT <= 1` |
| 1人2枠まで | `MAX_PER_STUDENT <= 2` |
| 学籍番号不備なし | `INVALID_ID == 0` |
| 氏名差異なし | `NAME_MISMATCH == 0` |
| クラス不一致なし | `CLASS_MISMATCH == 0` |
| 入力不備をまとめて禁止 | `INVALID_ID == 0 && NAME_MISMATCH == 0 && CLASS_MISMATCH == 0 && PENDING == 0` |

## 17. 設定例

男子のみの競技をエラーにする例：

| 列 | 入力例 |
|---|---|
| `rule_id` | `R101` |
| `有効` | チェック |
| `ルール名` | `男子のみ` |
| `判定` | `エラー` |
| `表示メッセージ` | `この競技には男子だけを登録してください` |
| `論理式（TRUEなら問題なし）` | `M > 0 && F == 0 && UNKNOWN == 0` |
| 対象競技 | 男子競技へチェック |

男女各2名以上を警告にする例：

| 列 | 入力例 |
|---|---|
| `rule_id` | `R102` |
| `有効` | チェック |
| `ルール名` | `男女各2名以上を推奨` |
| `判定` | `警告` |
| `表示メッセージ` | `男子・女子を各2名以上にできるか確認してください` |
| `論理式（TRUEなら問題なし）` | `M >= 2 && F >= 2 && UNKNOWN == 0` |
| 対象競技 | 混合競技へチェック |
